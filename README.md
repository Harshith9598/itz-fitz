# Itz Fizz — Scroll-Driven Hero

A responsive, single-page product story built with HTML, CSS, JavaScript, GSAP, and ScrollTrigger. The hero headline and impact stats reveal on load; the product can then moves with scroll progress through a pinned story section.

## Run locally

Open `index.html` in a browser, or serve the project directory with any static file server. GSAP and the display fonts are loaded from CDNs, so an internet connection is needed for those enhancements.

## Publish with GitHub Pages

Create a GitHub repository, push these files to its `main` branch, then select **Settings → Pages → Deploy from a branch → `main` / `(root)`**. The project is static and needs no build step. Your live URL will be `https://<your-username>.github.io/<repository-name>/`.
